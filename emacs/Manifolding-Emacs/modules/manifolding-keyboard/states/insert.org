#+title: Manifolding Keyboard — Insert State
#+priority: 20

Keys specific to the insert state. Shared bindings live in universal.org.

** Owned functions
#+begin_src emacs-lisp
(defun my/smart-escape ()
  "Return to the appropriate modal state based on the current buffer."
  (interactive)
  (cond
   ((derived-mode-p 'org-mode)   (manifolding-keyboard-set-state "org"))
   (t                            (manifolding-keyboard-set-state "normal"))))
#+end_src
** Bindings
#+begin_src emacs-lisp
(manifolding-keyboard-define-keys
  :states '("insert")
  :bind
  `(
    ("ESC" . my/smart-escape)
))
#+end_src
