** Atomic undo wrapper (Meow-extracted, ~my/wrap-collapse-undo~)
Extracted from ~meow--wrap-collapse-undo~ (meow-util.el:569–589, meow 1.5.0,
GPLv3). Runs a body of multiple edits but collapses them into a SINGLE undo
step via change groups, so downstream undo/undo-amalgamate behave atomically.
If the body signals an error the change group is cancelled instead. Layout-
independent, Dvorak-safe. Useful for multi-step edit commands (replace-all,
bulk ks/visual edits) that should feel like one atomic operation.
#+begin_src emacs-lisp
#+end_src

Concrete bound consumer: the normal zap does ~ks-goto-char-timer~ + ~kill-region~
(two undo steps). Wrapping it in ~my/wrap-collapse-undo~ collapses the whole zap
into a single undo step. Bound to ~z~ in the Key Selection › Zap menu.
#+begin_src emacs-lisp
(defun my/ks-zap-to-char-atomic ()
  "Zap to a key-selection-selected char as ONE atomic undo step.

Like ~my/ks-zap-to-char-inclusive~ but the timer jump + kill happen inside
~my/wrap-collapse-undo~, so undoing (vundo) reverts the whole zap at once."
  (interactive)
  (my/wrap-collapse-undo
    (let ((start (point)))
      (ks-goto-char-timer)
      (forward-char 1)
      (kill-region start (point)))))
#+end_src
