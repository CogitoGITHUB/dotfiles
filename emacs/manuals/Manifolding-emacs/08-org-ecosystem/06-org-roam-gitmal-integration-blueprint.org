* Org Roam + Gitmal Integration Blueprint
  :PROPERTIES:
  :AUTHOR: Shapeshifter
  :DATE: 2026-01-02
  :END:

** 1. Repository Layout
   - ~/org-roam/
     - notes/           ; your org-roam nodes
     - assets/          ; images, diagrams, PDFs
     - config.el        ; org-roam configuration
     - org-roam.db      ; generated DB (optional to gitignore)
   - ~/org-roam/.git    ; git repository

** 2. Org Export Workflow
   - Ensure each org node has:
     - #+TITLE: Node Title
     - #+DATE: YYYY-MM-DD
     - #+OPTIONS: toc:nil
     - Tags and properties for filtering
   - Export org files to Markdown for Gitmal:
     #+BEGIN_SRC emacs-lisp :tangle no
     (require 'ox-md)
     (org-md-export-to-markdown)
     #+END_SRC
   - Alternatively, export to HTML:
     #+BEGIN_SRC emacs-lisp :tangle no
     (require 'ox-html)
     (org-html-export-to-html)
     #+END_SRC
   - Place exports in a consistent folder (e.g., build/)

** 3. Git Versioning
   - Initialize repo: `git init`
   - Stage all: `git add .`
   - Commit: `git commit -m "Initial Org Roam export"`
   - Remote setup:
     #+BEGIN_SRC sh :tangle no
     git remote add origin <repo-url>
     git push -u origin main
     #+END_SRC

** 4. Gitmal Build
   - Install Gitmal: follow official instructions
   - From repo root, build static site:
     #+BEGIN_SRC sh :tangle no
     gitmal build -o site
     #+END_SRC
   - Optional: automate via git hook `.git/hooks/post-receive`:
     #+BEGIN_SRC sh :tangle no
     #!/bin/sh
     cd /path/to/org-roam
     gitmal build -o site
     #+END_SRC

** 5. Linking Org Roam Nodes in Gitmal
   - Preserve org-roam node IDs or slugs for HTML links:
     - [[id:1234567890abcdef][Node Title]] → becomes clickable link in HTML
   - Optional: post-process Gitmal HTML to add backlinks
   - Consider script to convert org-roam [[link]] syntax to <a href="...">

** 6. Automation in Emacs
   - Add after-save-hook for notes:
     #+BEGIN_SRC emacs-lisp :tangle no
     (defun publish-org-roam-node ()
       (when (string-prefix-p "~/org-roam/notes/" buffer-file-name)
         (org-md-export-to-markdown)
         (shell-command "git add . && git commit -m 'Auto-export' && gitmal build -o site")))
     (add-hook 'after-save-hook 'publish-org-roam-node)
     #+END_SRC
   - Integrate with Kanata modal keys for single-command publishing

** 7. Workflow Map
   - Org Roam Notes
     -> export to Markdown/HTML
        -> git commit & push
           -> Gitmal build
              -> Static browsable site

** 8. Optional Enhancements
   - Add custom CSS to Gitmal to mirror Org Roam UI style
   - Use Gitmal dark/light theme for visual coherence
   - Include assets folder in site output for images, diagrams
   - Script to update backlinks dynamically in exported HTML
