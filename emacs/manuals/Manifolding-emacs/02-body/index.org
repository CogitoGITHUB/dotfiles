#+title: Stage 02 — Body (embodiment)

Buffers breathe, windows posture, frames orient; display is the
skin, cursor the focus. Lifecycle order: containers first
(buffers → windows → frames), then location (positions), then the
giant display territory whole, then the small tools that move
through it (pulsar, center lock, switch-window, move-text).
