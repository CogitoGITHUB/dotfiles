* Yolk Overview
Yolk is a dotfile management and templating system that allows you to embed logic directly into configuration files.
It generates machine-specific configs from a canonical template, preserving per-host differences while keeping a single source of truth.

** Philosophy
- Treat configuration files as living templates.
- Embed logic inside files using Rhai scripting.
- Generate machine-specific configs without duplicating files.
- Integrates with version control for clean history and reproducibility.

** Core Concepts
- Template: A single canonical file with optional Yolk blocks (`# [yolk] ... # [/yolk]`) that can contain conditional logic.
- Data Layer: Variables representing machine traits (hostname, role, GPU, keyboard layout, etc.) stored in `data.rhai`.
- Output: Generated machine-specific configuration files in their respective application directories (e.g., `~/.config/nushell/config.nu`).

** Folder Structure Example
#+BEGIN_SRC text
~/AeonCore/
  yolk/
    yolk.rhai        # logic controlling generation
    data.rhai        # host traits
  configs/
    emacs/
      init.el.rhai
    qtile/
      config.py.rhai
    nushell/
      config.nu.rhai
#+END_SRC

** Example: Host-Adaptive Configuration
#+BEGIN_SRC text
# [yolk]
if (yolk.data("role") == "mapping") {
    out("font_size = 16")
} else {
    out("font_size = 12")
}
# [/yolk]
background = "#000000"
#+END_SRC

** Integration with Guix/OSTree
- Guix builds the environment (packages, paths, services)
- Yolk reads machine/system data to generate configs dynamically
- OSTree snapshots preserve history and atomicity
- Org-mode documents and triggers the process via babel blocks

** Org-Mode Control Example
#+BEGIN_SRC bash :results none
cd ~/AeonCore
yolk apply configs/
#+END_SRC

** Profiles / Personas
- `dev`, `ai`, `security`, `ritual`, `mapping`, `music`, `drawing`
- Switching persona triggers different config outputs
- Can be managed inside `data.rhai` and controlled via Org

** Summary
Yolk allows for:
- Dynamic, host-specific configuration generation
- Single source of truth for all configs
- Integration with Emacs/Org for orchestration
- Shapeshifting systems controlled declaratively
